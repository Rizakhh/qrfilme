# Instruções de manutenção — QR FILME

- Mantenha HTML, CSS e JavaScript puros; não adicione frameworks sem solicitação explícita.
- Preserve a paleta oficial: `#005f61`, `#007f82`, `#249fa1`, `#faac35`, `#f88105` e `#fd5a00`.
- Mantenha o português brasileiro e não invente dados institucionais, endereços, episódios ou métricas.
- Preserve WCAG 2.2 AA como objetivo: foco visível, teclado, contraste, alt text, headings e mensagens acessíveis.
- Não remova o link “Pular para o conteúdo”, os estados ARIA do menu ou a mensagem `aria-live` do compartilhamento.
- Mantenha caminhos relativos para compatibilidade com GitHub Pages em subdiretório.
- Evite dependências externas, scripts remotos e analytics sem identificador real.
- Preserve os assets existentes em `img/` e documente qualquer novo asset no README.
- Não crie mapa, geolocalização, login, cadastro, formulário de newsletter, player ou backend sem nova solicitação.
- Teste a navegação por teclado, o menu mobile, o Escape, o compartilhamento, o QR Code e as larguras de 320 px a 1440 px.
- Valide links e imagens antes de entregar uma alteração.
